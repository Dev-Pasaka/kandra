KandraTestBackend

object KandraTestBackend

Connection provider for live-cluster tests: one abstraction over the shared Testcontainers Cassandra (KandraTestcontainers) and the env-driven Scylla Cloud cluster (KandraCloud).

Selected by KANDRA_TEST_BACKEND: unset / docker (default, behaviour unchanged) or cloud (requires the KANDRA_CLOUD_* env, see KandraCloud; TLS via KANDRA_CLOUD_TLS=true).

Tests read connection facts from here instead of KandraTestcontainers.container:

install(Kandra) {
    contactPoints = KandraTestBackend.contactPointsCsv
    localDatacenter = KandraTestBackend.localDatacenter
    keyspace = KandraTestBackend.keyspaceName("ktor")
}
KandraTestBackend.newSession().use { it.execute("DROP KEYSPACE IF EXISTS $ks") }

All sessions built here use a 30s request timeout (the driver's 2s default is too tight for DDL against a freshly started container under load, and for WAN latency to the cloud cluster).
