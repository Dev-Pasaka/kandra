abstract fun up(session: CqlSession)

open fun up(session: CqlSession, keyspace: String?)

Entry point the runner actually calls (ISS-108). keyspace is the keyspace the KandraMigrationRunner targets, or null when it uses the session's current keyspace. Defaults to delegating to up, so existing migrations are unaffected (and their checksums unchanged). Override this instead of up only if the body needs the target keyspace; when a runner targets a non-session keyspace, migration CQL must qualify its own table names (CREATE TABLE ks.users ...) because the shared session is not switched.
