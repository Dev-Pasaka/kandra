EntityReflection

data class EntityReflection(val copyFunction: KFunction<*>?, val copyParameters: List<KParameter>, val propertiesByName: Map<String, KProperty1<*, *>>, val primaryConstructor: KFunction<*>?, val constructorParameters: List<KParameter>, val columnsByProperty: Map<String, ColumnSchema>)

The reflection surface needed to read/write an entity's fields at runtime, resolved once per entity kotlin.reflect.KClass at io.kandra.core.SchemaRegistry.register time and cached on TableSchema.reflection.

Before this existed, kandra-runtime re-resolved entity::class.memberFunctions.find { it.name == "copy" } and entity::class.memberProperties.associateBy { it.name } via Kotlin reflection on every single save()/update()/delete()/row-decode call — a linear scan repeated per call instead of once per entity type. See ISS-034 / GitHub #13.
